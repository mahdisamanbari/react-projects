# Scroll Indicator

A simple React application that displays a scroll progress indicator while scrolling through the page.

## Features

- Displays a scroll progress indicator
- Updates the indicator while scrolling

## Technologies

- React
- JavaScript
- CSS

## Getting Started

### Installation

npm install

### Run the development server

npm run dev

## What I Learned

- How to track scroll progress in React
- How to use `useState` and `useEffect`
- How to update the scroll indicator based on the page scroll position
